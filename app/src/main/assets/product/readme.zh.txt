AndMX 是 Android 上的编程 Agent。你可以打开项目、阅读代码、审批改动并检查结果。

首次试用
在设置中打开「快速入门」。离线样例可以练习拒绝、批准、查看差异和还原。要使用自己的文件，先配置并测试模型，再导入不超过 32 KB 的 UTF-8 文本。审阅后可另存副本。

操作项目
从工作台选择项目，用 @ 引用文件。构建模式下可审阅工具的输入和提议。打开「文件改动」查看差异，确认后可还原已记录的修改。

检查权限
设置中的「隐私与权限」列出系统授权状态、数据去向和对应的功能入口。模型请求使用你选择的供应商和端点。应用更新可以关闭自动检查。

获取帮助
关于页提供版本、第三方组件、贡献和 GitHub 问题入口。可以预览诊断信息，确认后复制。
