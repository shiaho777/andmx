AndMX is a coding agent for Android. Use it to open a project, read code, review proposed edits, and inspect the results.

Your first task
Open Quick start in Settings. The offline sample lets you decline, approve, inspect, and restore an edit. For your own file, configure and test a model first, then import a UTF-8 text file of up to 32 KB. Review the proposed edit and save a copy.

Working in a project
Choose a project in the workbench and type @ to reference files. In Build mode, review tool inputs and proposals when asked. Open File changes to inspect diffs and confirm restoration of recorded edits.

Managing permissions
Privacy and permissions shows Android authorization status, data destinations, and links to the relevant settings. Model requests use your chosen provider and endpoint. App updates lets you turn off automatic checks.

Getting help
About links to third-party notices, the contribution guide, and GitHub issues. Preview build diagnostics before copying them.
