# Changelog

## 1.0.0

AndMX for ARM64 Android.

- Start the built-in Alpine Linux environment offline. The terminal and Agent commands share the selected project.
- Build and install a single AndMX app. The signed package is named `andmx.1.0.0.APK`.
- Use the workbench to browse project files, search conversations, and review edits with diffs, approvals and revert actions.
- Start with the offline sample or import a small text file. Confirm the selected model before sending it, then review the proposed change and save a separate copy.
- Set up model providers, inspect Android permissions and data destinations, and preview diagnostics before copying.
- Check for stable GitHub releases and verify the APK, version and signing certificate before opening the Android installer.

## 0.1.0-preview.1

- Try file approvals, diffs, and restoration in a private offline sample.
- Pick one small UTF-8 file, approve sending it to your configured model, and review its proposed revision before saving a separate copy.
- Review permissions and their data destinations, preview a minimal diagnostic bundle, and check for signed GitHub preview updates.

The preview targets ARM64 Android and uses the Lite engine.
